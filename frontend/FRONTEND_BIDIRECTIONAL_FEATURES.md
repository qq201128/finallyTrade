# 前端双向交易功能说明

## ✅ 已添加的功能

### 1. 策略管理页面（Strategies.vue）

#### 新增配置选项

在策略添加/编辑对话框中添加了两个开关：

1. **双向交易开关**
   - 位置：策略配置表单
   - 功能：启用/禁用双向交易功能
   - 说明：开启后支持同时持有多头和空头仓位，支持双向补仓和平仓

2. **仓位调整开关**
   - 位置：策略配置表单
   - 功能：启用/禁用自动仓位调整
   - 说明：开启后允许策略自动调整仓位（加仓/减仓）

#### 新增显示列

在"我的策略"表格中新增了"双向交易"列：
- 显示策略是否启用了双向交易
- 使用标签显示：绿色（是）/灰色（否）

### 2. 持仓管理页面（Positions.vue）

#### 新增持仓统计卡片

在页面顶部添加了4个统计卡片：

1. **总持仓数**
   - 显示所有持仓的总数

2. **多头持仓**
   - 显示long持仓数量
   - 绿色显示

3. **空头持仓**
   - 显示short持仓数量
   - 红色显示

4. **总未实现盈亏**
   - 显示所有持仓的未实现盈亏总和
   - 绿色（盈利）/红色（亏损）

#### 新增持仓筛选功能

在"当前持仓"标签页添加了筛选器：
- **全部**：显示所有持仓
- **多头**：只显示long持仓
- **空头**：只显示short持仓

#### 优化持仓方向显示

- 使用标签显示持仓方向
- Long持仓：绿色标签显示"做多"
- Short持仓：红色标签显示"做空"

## 使用流程

### 启用双向交易

1. **进入策略管理页面**
   - 点击"添加策略"或"编辑"按钮

2. **配置双向交易**
   - 在对话框中找到"双向交易"开关
   - 开启开关
   - （可选）开启"仓位调整"开关

3. **保存配置**
   - 点击"确定"或"保存"按钮
   - 系统会自动使用双向交易引擎

### 查看双向持仓

1. **进入持仓管理页面**
   - 查看顶部的统计卡片
   - 可以看到多头和空头的分别统计

2. **筛选持仓**
   - 使用筛选器查看特定方向的持仓
   - 点击"多头"只显示long持仓
   - 点击"空头"只显示short持仓

## 技术实现

### 数据绑定

```javascript
// 表单数据
const form = reactive({
  // ...
  bidirectional_trading: false,  // 双向交易开关
  position_adjustment: false,     // 仓位调整开关
  config: {}
})

// 提交时合并到config
config: {
  ...form.config,
  bidirectional_trading: form.bidirectional_trading,
  position_adjustment: form.position_adjustment
}
```

### 持仓筛选

```javascript
// 筛选后的持仓
const filteredPositions = computed(() => {
  if (positionFilter.value === 'all') {
    return positions.value
  } else if (positionFilter.value === 'long') {
    return positions.value.filter(p => p.side === 'long')
  } else {
    return positions.value.filter(p => p.side === 'short')
  }
})
```

### 统计计算

```javascript
// 多头持仓数
const longPositionsCount = computed(() => {
  return positions.value.filter(p => p.side === 'long').length
})

// 空头持仓数
const shortPositionsCount = computed(() => {
  return positions.value.filter(p => p.side === 'short').length
})

// 总未实现盈亏
const totalUnrealizedPnl = computed(() => {
  return positions.value.reduce((sum, p) => sum + (p.unrealized_pnl || 0), 0)
})
```

## 注意事项

1. **配置保存**：双向交易配置保存在 `config.bidirectional_trading` 中
2. **向后兼容**：如果策略没有配置，默认显示"否"
3. **实时更新**：持仓数据通过WebSocket实时更新
4. **筛选状态**：筛选器状态不会持久化，刷新后重置为"全部"
